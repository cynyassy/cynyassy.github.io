# Portfolio Features Overview

## 🎨 Visual Design System

### Color Philosophy
- **Black & White Foundation**: Creates high contrast and clarity
- **Single Accent Color** (#FF4400): Orange-red used exclusively for:
  - Interactive elements on hover
  - Active states
  - Call-to-action buttons
  - Progress indicators
  - Important highlights

### Comic-Inspired Elements
- Hand-drawn SVG illustrations throughout
- Slightly imperfect alignments (intentional)
- Comic panel-style sections
- Dashed lines and decorative patterns
- Geometric shapes as background elements

## ⚡ Interactive Features

### 1. Custom Cursor (Desktop Only)
- **What**: Custom-designed cursor with outer ring
- **When**: Desktop devices with mouse
- **Effect**: Expands on hover over clickable elements
- **Style**: Mix-blend-difference for visibility on any background

### 2. Skills Network Visualization
- **What**: Interactive SVG network diagram
- **Center Node**: Shashank/Cynyassy
- **5 Skill Clusters**: Design, Systems/Product, Tech, Storytelling, Growth
- **Interactions**:
  - Hover: Highlights connections, changes color to accent
  - Click: Expands to show sub-skills (5 per cluster)
  - Visual feedback with smooth animations

### 3. Interactive Play Section
- **What**: Floating balloon elements with hidden insights
- **Interactions**:
  - Balloons float up and down continuously
  - Click to reveal personal thoughts/beliefs
  - Tooltips appear for 5 seconds
  - Each balloon has unique content
- **Purpose**: Humanizes the portfolio, shows personality

### 4. Horizontal Clients Carousel
- **What**: Scrollable client showcase
- **Features**:
  - 9 client cards
  - Left/right navigation arrows (desktop)
  - Swipe on mobile
  - Hover reveals role and year
  - Shadow effect on hover
  - Accent corner triangles

### 5. Smooth Scroll Navigation
- **What**: Fixed navigation bar with section jumps
- **Features**:
  - Appears after scrolling past hero
  - 4 main navigation items
  - Smooth scroll to sections
  - Mobile hamburger menu
  - Active state indicators

### 6. Scroll-to-Top Button
- **What**: Fixed button in bottom-right
- **Behavior**:
  - Appears after scrolling 500px down
  - Smooth animation in/out
  - Hover lift effect
  - Changes to accent color on hover

### 7. Loading Screen
- **What**: Animated initial experience
- **Features**:
  - Progress bar (0-100%)
  - Animated logo/name
  - Comic-style loading graphic
  - Fades out when complete

## 💡 Design Decisions

### Why Black & White?
- Maximum clarity
- Focus on content
- Professional yet creative
- Comic/print aesthetic
- Accent color stands out

### Why Comic-Inspired?
- Shows personality
- Memorable aesthetic
- Supports storytelling narrative
- Balances professional/creative
- Unique in portfolio space

### Why Interactive Elements?
- Demonstrates technical skill
- Engages visitors longer
- Makes experience memorable
- Shows attention to detail
- Reflects systems thinking

### Why Minimal Accent Color?
- Creates visual hierarchy
- Guides user attention
- Maintains cohesion
- Professional restraint
- Intentional design
