## Mars Reactor artwork

Original cinematic illustration generated for Cynyassy with imagegen on 12 October 2026. Optimised derivatives are reactor-mars-desktop.webp (1920 px, 217860 bytes) and reactor-mars-mobile.webp (960 px, 66622 bytes). Both retain the complete composition.

The base illustration has six unlit window bands. ReactorScene overlays lights and effects in a 2048 × 684 coordinate space matching the image composition; preserveAspectRatio and object-fit contain keep the reactor uncropped. Runtime art is loaded only with the lazily imported ReactorPage.

The original generated image remains in the Codex generated_images directory; these project-local derivatives are the delivered assets.
